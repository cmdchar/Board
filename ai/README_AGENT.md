- Actualizeaza `ai/BRAINMAP.md`.

4) Daca schimbi schema datelor:
- Actualizeaza `ai/database.md`.

5) La comanda "continue":
- Reia din `ai/BRAIN.md`, sectiunea `Next Steps (Exact)`.
