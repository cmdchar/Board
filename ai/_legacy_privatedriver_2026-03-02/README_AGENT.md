# AI WORKFLOW RULES (MANDATORY)

You must follow this workflow at ALL TIMES:

1) BEFORE writing or modifying code:
   - Read /ai/BRAIN.md and /ai/TASKS.md
   - Add or update the current task in TASKS.md

2) AFTER modifying ANY file:
   - Add an entry in /ai/CHANGELOG_AI.md describing:
     - what changed
     - which files
     - why

3) WHEN you finish a response, hit a complexity limit, or are told "continue":
   - Update /ai/BRAIN.md:
     - In Progress (NOW)
     - Next Steps (Exact)

4) If architecture or structure changes:
   - Record it in /ai/DECISIONS.md

5) When user says "continue":
   - FIRST read BRAIN.md
   - Resume from "Next Steps (Exact)" step 1

This system is your persistent memory. Never ignore it.
